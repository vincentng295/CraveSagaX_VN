Crave Saga X là game nhập vai chiến thuật theo lượt lấy bối cảnh tại Vesteria — thế giới song song giả tưởng nơi chỉ có nam giới thuộc nhiều chủng tộc sinh sống, chịu sự chi phối giữa hai thế lực đối lập.

Phe thiên thần muốn dẫn dắt nhân loại đến một utopia lý tưởng, trong khi phe ác quỷ theo đuổi tham vọng và sự đồi trụy. Người chơi vào vai "Master", được Thần Sáng tạo và Vua Thần nguyên thủy Arche tái sinh tại Vesteria để bắt đầu hành trình phiêu lưu và cứu rỗi thế giới.

Miễn phí & mã nguồn mở

Toàn bộ code công khai trên GitHub — anh em thoải mái kiểm tra, học hỏi, hoặc cùng đóng góp phát triển dự án.

Cảnh báo an toàn — Bảo mật tài khoản

Không sử dụng extension từ nguồn gốc không rõ nhằm tránh bị đánh cắp thông tin đăng nhập, token session hoặc tài khoản game của bạn.

  1. Chỉ tải tiện ích từ Repositories / Releases chính thức tại GitHub này.
  2. Tuyệt đối KHÔNG sử dụng các file .crx, .zip hoặc bản mod phát tán qua các đường link trôi nổi, không rõ nguồn gốc.
  3. Anh em biết lập trình có thể thoải mái soi code trực tiếp ngay tại repo này để yên tâm sử dụng.

Hướng dẫn cài đặt

Chọn nền tảng bạn đang dùng để xem các bước cài đặt tương ứng.

01

Tải mã nguồn

Tải bản Source code (zip) mới nhất về máy và giải nén.

02

Mở trang quản lý tiện ích

Truy cập đường dẫn chrome://extensions/ trên trình duyệt Chrome (hoặc Edge, Opera, Brave).

03

Bật chế độ dành cho nhà phát triển

Gạt công tắc Developer mode ở góc trên bên phải sang trạng thái BẬT (On).

04

Tải tiện ích đã giải nén

Nhấn Load unpacked ở góc trên bên trái, sau đó chọn thư mục chứa mã nguồn vừa giải nén.

05

Ghim tiện ích

Tìm tiện ích tên Crave Saga X Tiếng Việt và ghim lên thanh công cụ để dễ thao tác khi chơi.

01

Tải Edge Canary

Cài đặt trình duyệt Edge Canary từ Google Play — trình duyệt di động thông thường không hỗ trợ tiện ích chưa đóng gói.

02

Tải file CRX

Tải file extension.crx trực tiếp về thiết bị Android.

03

Kích hoạt Developer Options

Mở Edge Canary → Cài đặt → Về Microsoft Edge. Nhấn liên tục 5–7 lần vào logo phiên bản Edge cho đến khi xuất hiện thông báo kích hoạt.

04

Cài đặt tiện ích

Quay lại menu Cài đặt → Developer Options → Extension install by crx → chọn file extension.crx đã tải → nhấn OK.

05

Quản lý extension

Extension sẽ xuất hiện trong danh sách quản lý của Edge Canary, sẵn sàng sử dụng khi vào game.
